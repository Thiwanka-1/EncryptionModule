The badge on each bench is the Java Cipher transformation these settings correspond to, so output matches Java, OpenSSL and most other tools when the same raw key and IV are used. Plain-text keys count one byte per ASCII character. An empty IV means sixteen zero bytes, as most libraries assume. GCM appends its 16-byte authentication tag to the ciphertext.

Ctrl+Enter in a text box runs that bench. Mode, padding, key size and format choices are remembered on this device; keys and text are not.
